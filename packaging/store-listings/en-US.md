# en-US

## Title

EpubMerge - EPUB Merger

## Short description

Combine EPUB books in your chosen order, customize the title and cover, and create an EPUB 3 file with navigation.

## Description

Bring multiple EPUB books together in one file to organize series, volumes and reading material. EpubMerge offers a straightforward Windows interface: add your books, arrange their order, choose an output location and start merging.

Import EPUB 2 and EPUB 3 files and create an EPUB 3 output. Each source book remains a top-level group in the merged contents, with regenerated navigation and a table of contents. Set a custom title, choose a cover image or extract a cover from an input book.

Reorder books by dragging or using buttons. Import EPUB files from folders, optionally including subfolders. Follow merge progress, cancel a running task or restore settings from recent tasks. When finished, open the output file or locate its folder.

Choose from ten interface languages and system, light or dark themes. The first launch matches a supported system language; explicit language choices are remembered.

Source EPUB files are read only and are not modified. Keep backups and check the output; compatibility with every EPUB or reader is not guaranteed. Encrypted or font-obfuscated EPUB files containing META-INF/encryption.xml are not supported, and the app does not remove DRM. Only process content you own or are authorized to use, in accordance with applicable copyright laws and license terms.

## Features

- Merge EPUB 2 and EPUB 3 inputs into EPUB 3 with navigation
- Drag to reorder and preserve a contents group for each source book
- Customize the title, output path and cover
- Import EPUB files from folders and subfolders
- Preview covers and extract or export a source book cover
- Restore recent tasks, track progress and cancel merges
- Ten interface languages with system, light and dark themes
