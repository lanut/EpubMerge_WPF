# ja-JP

## Title

EpubMerge - EPUB 結合ツール

## Short description

EPUB の電子書籍を好きな順序で結合。タイトルと表紙を設定し、ナビゲーション付きの EPUB 3 ファイルを作成できます。

## Description

複数の EPUB をひとつにまとめ、シリーズ作品や分冊、読書資料を整理できます。EpubMerge は Windows 向けのシンプルな結合ツールです。本を追加し、順序と保存先を指定して結合を開始します。

EPUB 2 と EPUB 3 を読み込み、EPUB 3 として出力します。元の本ごとのグループを目次の最上位に保持し、ナビゲーションと目次を再生成します。タイトルを変更したり、画像を表紙に設定したり、元の本から表紙を抽出したりできます。

ドラッグ操作やボタンで順序を変更できます。フォルダーからの取り込みでは、サブフォルダーを含めることも可能です。進行状況の確認、実行中の処理のキャンセル、最近のタスクからの設定復元に対応しています。完了後は出力ファイルや保存先フォルダーを開けます。

画面は 10 言語に対応し、システム設定に従うテーマ、ライトテーマ、ダークテーマを選べます。初回起動時は対応するシステム言語を使用し、手動で選んだ言語を記憶します。

元の EPUB は読み取り専用で扱い、変更しません。バックアップを保存し、出力を確認してください。すべての EPUB やリーダーとの互換性は保証されません。META-INF/encryption.xml を含む暗号化またはフォント難読化された EPUB は非対応で、DRM の解除も行いません。所有または利用許諾を得たコンテンツのみを、適用される著作権法とライセンス条件に従って処理してください。

## Features

- EPUB 2 と EPUB 3 を結合し、ナビゲーション付き EPUB 3 を出力
- ドラッグで並べ替え、元の本ごとの目次グループを保持
- タイトル、保存先、表紙を設定
- フォルダーとサブフォルダーから EPUB を追加
- 表紙のプレビュー、抽出、書き出し
- 最近のタスクの復元、進行状況の表示、キャンセル
- 10 言語とシステム、ライト、ダークのテーマ
