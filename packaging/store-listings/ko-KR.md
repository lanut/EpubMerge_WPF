# ko-KR

## Title

EpubMerge - EPUB 병합 도구

## Short description

EPUB 전자책을 원하는 순서로 합치고 제목과 표지를 설정하여 탐색 목차가 포함된 EPUB 3 파일을 만드세요.

## Description

여러 EPUB 전자책을 하나로 합쳐 시리즈, 분권 도서와 읽기 자료를 정리하세요. EpubMerge는 Windows용 간편한 병합 도구입니다. 책을 추가하고 순서와 저장 위치를 정한 다음 병합을 시작하면 됩니다.

EPUB 2와 EPUB 3 파일을 읽어 EPUB 3로 출력합니다. 원본 책마다 병합 목차의 최상위 그룹을 유지하고 탐색 페이지와 목차를 다시 생성합니다. 제목을 지정하거나 표지 이미지를 선택하거나 원본 책에서 표지를 추출할 수 있습니다.

끌어서 놓기나 버튼으로 순서를 바꾸세요. 폴더에서 EPUB를 가져올 때 하위 폴더도 포함할 수 있습니다. 진행 상황을 확인하고 작업을 취소하거나 최근 작업에서 설정을 복원하세요. 완료 후 출력 파일이나 해당 폴더를 열 수 있습니다.

10개 인터페이스 언어와 시스템, 밝은 테마, 어두운 테마를 제공합니다. 처음 실행할 때 지원되는 시스템 언어를 선택하며, 사용자가 직접 선택한 언어를 기억합니다.

원본 EPUB는 읽기 전용으로 처리하며 변경하지 않습니다. 백업을 보관하고 결과를 확인하세요. 모든 EPUB나 전자책 리더와의 호환성은 보장되지 않습니다. META-INF/encryption.xml이 포함된 암호화 또는 글꼴 난독화 EPUB는 지원하지 않으며 DRM을 제거하지 않습니다. 소유하거나 사용 권한이 있는 콘텐츠만 관련 저작권법과 라이선스 조건에 따라 처리하세요.

## Features

- EPUB 2와 EPUB 3를 병합하여 탐색 목차가 있는 EPUB 3 출력
- 끌어서 순서 변경 및 원본 책별 목차 그룹 유지
- 제목, 출력 경로, 표지 사용자 지정
- 폴더 및 하위 폴더에서 EPUB 가져오기
- 표지 미리 보기, 추출 및 내보내기
- 최근 작업 복원, 진행 상황 확인 및 병합 취소
- 10개 언어와 시스템, 밝은 테마, 어두운 테마
