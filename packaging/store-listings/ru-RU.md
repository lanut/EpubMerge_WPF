# ru-RU

## Title

EpubMerge - Объединение EPUB

## Short description

Объединяйте книги EPUB в нужном порядке, задавайте название и обложку и создавайте файл EPUB 3 с навигацией.

## Description

Соберите несколько книг EPUB в один файл, чтобы упорядочить серии, тома и материалы для чтения. EpubMerge предлагает простой интерфейс для Windows: добавьте книги, выберите порядок и путь сохранения, затем запустите объединение.

Приложение читает EPUB 2 и EPUB 3 и создаёт EPUB 3. Каждая исходная книга сохраняется как группа верхнего уровня в общем оглавлении. Навигация и оглавление создаются заново. Можно задать название, выбрать изображение обложки или извлечь обложку из исходной книги.

Меняйте порядок перетаскиванием или кнопками. Импортируйте EPUB из папок, при необходимости включая вложенные папки. Следите за ходом работы, отменяйте текущую задачу или восстанавливайте настройки недавних задач. После завершения откройте результат или папку с ним.

Интерфейс доступен на десяти языках, с системной, светлой и тёмной темами. При первом запуске выбирается поддерживаемый язык системы; ручной выбор языка сохраняется.

Исходные EPUB открываются только для чтения и не изменяются. Храните резервные копии и проверяйте результат: совместимость со всеми EPUB и программами чтения не гарантируется. Зашифрованные EPUB и EPUB с обфускацией шрифтов, содержащие META-INF/encryption.xml, не поддерживаются. Приложение не снимает DRM. Обрабатывайте только собственные материалы или материалы, на использование которых у вас есть разрешение, соблюдая применимое авторское право и условия лицензий.

## Features

- Объединение EPUB 2 и EPUB 3 в EPUB 3 с навигацией
- Сортировка перетаскиванием и группа оглавления для каждой книги
- Настройка названия, пути сохранения и обложки
- Импорт EPUB из папок и вложенных папок
- Просмотр, извлечение и экспорт обложек
- Восстановление недавних задач, отображение хода работы и отмена
- Десять языков, системная, светлая и тёмная темы
