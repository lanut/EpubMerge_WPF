## Title

EpubMerge - EPUB 合并工具

## Short description

按自定顺序合并 EPUB 电子书，设置书名与封面，生成带导航目录的 EPUB 3 文件。

## Description

将多本 EPUB 电子书整理成一本，方便管理系列作品、分卷和阅读资料。EpubMerge 为 Windows 提供直观的合并界面：添加文件、调整顺序、设置输出位置，然后开始合并。

支持 EPUB 2 和 EPUB 3 输入，输出 EPUB 3。每本源书在合并目录中保留为顶层项目，并重新生成导航页面和目录。可自定义合并书名，选择封面图片，或从输入书籍中提取封面。

通过拖放或按钮调整顺序，也可从文件夹导入 EPUB，并选择是否包含子文件夹。查看合并进度、取消正在进行的任务，或从历史任务恢复配置。完成后可打开生成文件或定位到其所在文件夹。

界面支持十种语言，并提供跟随系统、浅色和深色主题。首次启动匹配支持的系统语言，主动选择的语言会被记住。

源 EPUB 文件仅供读取，不会被修改。请保留备份并检查输出；不能保证所有 EPUB 或阅读器均兼容。不支持含 META-INF/encryption.xml 的加密或字体混淆 EPUB，也不移除 DRM。请仅处理你拥有或获授权使用的内容，并遵守适用版权与许可条款。

## Features

- 合并 EPUB 2 和 EPUB 3，输出带导航目录的 EPUB 3
- 拖放排序，按顺序保留各源书的目录分组
- 自定义书名、输出路径和封面
- 从文件夹及子文件夹导入 EPUB
- 预览封面，并提取或导出源书封面
- 历史任务恢复、合并进度与取消操作
- 十种界面语言及系统、浅色、深色主题
