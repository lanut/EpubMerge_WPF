# zh-TW

## Title

EpubMerge - EPUB 合併工具

## Short description

依自訂順序合併 EPUB 電子書，設定書名與封面，產生附導覽目錄的 EPUB 3 檔案。

## Description

將多本 EPUB 電子書整理成一本，方便管理系列作品、分冊與閱讀資料。EpubMerge 提供直覺的 Windows 操作介面：加入書籍、調整順序、選擇輸出位置，即可開始合併。

支援 EPUB 2 與 EPUB 3 輸入，輸出為 EPUB 3。每本來源書籍在合併目錄中保留為最上層群組，並重新產生導覽頁面與目錄。可自訂書名、選擇封面圖片，或從來源書籍擷取封面。

透過拖放或按鈕調整順序，也可從資料夾匯入 EPUB，並選擇是否包含子資料夾。查看合併進度、取消執行中的工作，或從最近的工作還原設定。完成後可開啟輸出檔案，或前往所在資料夾。

介面提供十種語言，以及跟隨系統、淺色和深色佈景主題。首次啟動會配對支援的系統語言，並記住使用者主動選取的語言。

來源 EPUB 僅供讀取，不會被修改。請保留備份並檢查輸出；不保證與所有 EPUB 或閱讀器相容。不支援含 META-INF/encryption.xml 的加密或字型混淆 EPUB，也不移除 DRM。請僅處理自己擁有或獲授權使用的內容，並遵守適用的著作權與授權條款。

## Features

- 合併 EPUB 2 與 EPUB 3，輸出附導覽目錄的 EPUB 3
- 拖放排序，保留各來源書籍的目錄群組
- 自訂書名、輸出路徑與封面
- 從資料夾及子資料夾匯入 EPUB
- 預覽封面，擷取或匯出來源書籍封面
- 還原最近的工作、查看進度與取消合併
- 十種介面語言及系統、淺色、深色主題
